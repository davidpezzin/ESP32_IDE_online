# ESP32 IDE Online

Uma IDE online para ESP32 que transforma o dispositivo em um pequeno ambiente de desenvolvimento via navegador.

## 📌 Sobre o projeto

O **ESP32 IDE Online** é um projeto que inicia um **servidor web no ESP32** e disponibiliza uma interface acessível pelo navegador, funcionando como um **gerenciador de arquivos** e ambiente de testes.

Com ele, é possível:

- acessar os arquivos armazenados no ESP32;
- criar, editar e organizar códigos diretamente pela web;
- testar alterações de forma prática no próprio ambiente online;
- reduzir a necessidade de conexão física por cabo para tarefas do dia a dia.

A proposta é facilitar prototipagem, testes e manutenção de projetos embarcados com mais agilidade e mobilidade.

## ⚙️ Funcionalidades

- Servidor web embarcado no ESP32
- Interface web para gerenciamento de arquivos
- Criação e edição de códigos pelo navegador
- Fluxo de testes online

## 🚀 Objetivo

Oferecer uma experiência simples e eficiente para desenvolvimento remoto/local com ESP32, centralizando em uma interface web recursos que normalmente exigiriam ferramentas externas e conexão por cabo.

## 🧪 Casos de uso

- Testes rápidos de código em bancada
- Ajustes e manutenção sem depender de IDE local
- Demonstrações de projetos IoT de forma mais interativa
- Organização de arquivos do firmware diretamente no dispositivo

## 📋 Requisitos básicos

- Placa ESP32
- Firmware do projeto carregado na placa
- Conexão de rede (Wi-Fi)
- Navegador web atualizado

## 🔐 Observações importantes

Como o ESP32 expõe uma interface web de gerenciamento, é recomendável:

- utilizar em rede confiável;
- aplicar autenticação, quando disponível;
- evitar exposição direta à internet sem camadas de segurança.
